1. Connect App to ESP32 using Bluetooth from Bluetooth Page in Quick Button [ + ] and search
   Bluetooth name with name "ESP32-PRESENCE".
2. Open Add Member page from Quick Button [ + ].
3. Tap the ID card of the new member you want to register on the RFID sensor on the ESP32 side. Wait
   a few seconds for the card to be detected in the app.
4. You will be given a form that must be filled in with new member data if the ID card has been
   detected in the application.
5. On the new member data entry form, you can simply provide their student ID number (NIM) for the
   system to automatically detect their data. However, you must upload an Excel file of all members
   to the application folder for the system to run smoothly. This will be discussed further later.
6. After you've filled in the new member's details, click the register button to register the new
   member in the database. That's it! You've successfully registered a new member using their ID
   card.
