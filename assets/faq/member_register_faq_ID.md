1. Hubungkan Aplikasi ke ESP32 menggunakan Bluetooth dari Halaman Bluetooth di Tombol Cepat [ + ]
   dan cari Nama Bluetooth dengan nama "ESP32-PRESENCE".
2. Buka halaman Tambah Anggota dari Tombol Cepat [ + ].
3. Sentuh kartu identitas anggota baru yang ingin Anda daftarkan pada sensor RFID di sisi ESP32.
   Tunggu beberapa detik hingga kartu terdeteksi di aplikasi.
4. Anda akan diberikan formulir yang harus diisi dengan data anggota baru jika kartu identitas telah
   terdeteksi dalam aplikasi.
5. Pada formulir input data anggota baru, Anda cukup memasukkan nomor induk mahasiswa (NIM) agar
   sistem dapat mendeteksi data mereka secara otomatis. Namun, Anda wajib mengunggah file Excel yang
   berisi daftar seluruh anggota ke dalam folder aplikasi agar sistem dapat berjalan dengan lancar.
   Hal ini akan dibahas lebih lanjut nanti.
6. Setelah mengisi data anggota baru, klik tombol daftar untuk mendaftarkan anggota tersebut ke
   dalam basis data. Selesai! Anda telah berhasil mendaftarkan anggota baru menggunakan kartu
   identitas mereka.
