1. Open Members Excel page from Quick Button [ + ].
2. Click upload icon on top right or if previous excel data has never existed it will appear in
   center of page.
3. Upload an Excel file format (only support .xlsl) from folder. You can also give a custom name
   that replace file name from folder. The file will be detected in the application.
4. Click Add button to add uploaded Excel to App folder. That's it! You've successfully uploaded an
   Excel file of members.
5. After the Excel file is uploaded, you can review the data and make any necessary changes from
   card option (swip card to left to see all option).
