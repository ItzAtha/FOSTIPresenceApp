1. Buka halaman Excel Anggota dari Tombol Cepat [ + ].
2. Klik ikon unggah di kanan atas atau jika data excel sebelumnya belum pernah ada, ikon tersebut
   akan muncul di tengah halaman.
3. Unggah file format Excel (hanya mendukung .xlsl) dari folder. Anda juga dapat memberikan nama
   khusus yang menggantikan nama file dari folder. File akan terdeteksi di aplikasi.
4. Klik tombol Tambah untuk menambahkan file Excel yang diunggah ke folder Aplikasi. Selesai! Anda
   telah berhasil mengunggah file Excel berisi data anggota.
5. Setelah file Excel diunggah, Anda dapat meninjau data dan melakukan perubahan yang diperlukan
   dari opsi kartu (geser kartu ke kiri untuk melihat semua opsi).
